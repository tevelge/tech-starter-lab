# Tech Starter Lab 🚀

An educational web application designed to introduce children (ages 10-12) to the software development lifecycle, demonstrating how simple and accessible building a tech product can be.

## 🔗 Links
* **Live Application:**  [Tech Starter Lab](https://tech-starter-lab.base44.app)

## 🎯 The Challenge
Bridging the gap in AI literacy for young learners. The goal was to make advanced AI tools approachable, intuitive, and engaging for kids, allowing them to experience product creation firsthand.

## 👩‍💻 My Role & Contributions
As part of the collaborative development team, my responsibilities included:
* **Core Logic:** Co-developed the underlying application logic and user flow structures.
* **AI Integration:** Worked directly with Large Language Models (LLMs) and engineered prompts to ensure age-appropriate, educational interactions.
* **UI/UX Design:** Contributed to designing a kid-friendly, intuitive interface tailored specifically for the target audience.

## 🛠️ Tech Stack
* **Platform:** Base44
* **Technologies:** Generative AI, Prompt Engineering, UI Design
